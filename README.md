# The Heston Model

Readable web version of the seminar paper **The Heston Model: Theory, Numerical Simulation and Calibration**.

**Read the seminar here:**  
https://noahbreidung.github.io/heston-model-paper/

**Additional seminar page:**  
https://noahbreidung.github.io/heston-model-paper/spde-numerics-seminar/

The page is designed as a chapter-based reader with a left-hand table of contents and properly rendered mathematical formulas. The original PDF is linked from the page.

This is a seminar and study project, not a production pricing library.
