# The Heston Model

Public GitHub Pages version of Noah Breidung's seminar paper:

**The Heston Model: Theory, Numerical Simulation and Calibration**

## Contents

- `index.html`: Project page with abstract, selected figures and embedded PDF.
- `assets/heston-model-paper.pdf`: Original paper.
- `assets/heston-paper-cover-01.png`: Rendered cover preview.
- `assets/figures/`: Selected numerical output figures.
- `.github/workflows/pages.yml`: GitHub Actions workflow for GitHub Pages.

After pushing this repository to GitHub, GitHub Pages can serve the site publicly.
